# BSC 私募退款工作台

静态网页，直接部署到 GitHub Pages。所有操作由连接的钱包签名并发送至 BSC 主网合约；页面不保存私钥。

本次固定退款：原私募地址 `0x0e566836cff38dde506ef70d9b7ef84b17e72ee9`，指定收款地址 `0xd53dd86b7a7aec21589ebb06de978e3cb714c11f`，金额 0.4 BNB。

管理员创建申请后，三位管理员各自连接钱包确认同一申请，最后由合约所有者执行。页面从链上自动查找匹配地址和金额的申请，无需分享本地状态；不操作其他收款地址的历史申请。发现相同地址及金额的多个申请时禁用确认和执行，要求先核对。

支持浏览器注入钱包（MetaMask 等）及兼容的钱包内置浏览器。每个动作都会显示收款地址、金额及申请号，并要求钱包确认。已执行状态以合约查询为准，页面可下载 Markdown 记录。页面不能直接改写电脑上的历史 Markdown 文件，需在成功执行后将凭证合并到对账清单。

本地测试：`node --test tests/*.test.js`。用任意静态 HTTP 服务打开根目录即可预览。
