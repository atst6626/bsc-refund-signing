# BSC 私募退款：合伙人逐笔确认

访问：https://atst6626.github.io/bsc-refund-signing/

本批32个原私募地址、51份、原路退款4.08 BNB。页面从BSC主网合约读取申请，两位合伙人各自连接钱包，逐笔核对收款地址、份数、金额和申请编号后发送确认交易。页面不接收私钥，不创建或执行退款。

管理员在本机程序批量创建申请并完成自己的确认；达到3/3后，在本机程序预览并批量执行。合伙人页面自动读取同一批链上状态，每30秒刷新。对清单外、不同金额、重复或已执行的申请不提供确认操作。

`batch.json` 为本批固定清单，金额均按付费份额×0.08 BNB计算。历史已结算地址不在本批。`admin-local/` 是仅本机使用的管理员程序，由 `.gitignore` 排除，不上传本仓库。

验证：`node --test tests/*.test.js`。全部交易只由钱包或用户自行解锁的本机管理员进程发送。
